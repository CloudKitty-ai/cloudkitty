# Scratch BC clone + per-γ critic pretrains on dataset v2 (exp-002 §7.1)

**Date**: 2026-08-03 · **Engine**: main @ `0fd551d`
(`engine_defaults_sha256` `12bf38624186…`) · **Dataset**: v2
(prereg §5 — 60 rollouts, 1,908,182 decisions, recollected post-025)
· **Split**: the frozen §5 scheme — val = `rollout-02` of every
variant + `s6-rollout-00` of configs 12/13/14 (42 train / 18 val
rollouts; 1,336,146 / 572,036 decisions).

**This compute froze the prereg** (STATUS flipped the same day,
commit `c527cf4`). The clone seeds arm C-scratch and its honest
kitty-eval numbers are recorded below, but it is **not a registered
arm** this generation (§7.1). Critic pretrains initialize the
γ-matched critics of every arm, never reused across γ (§5).

## Clone (behavior cloning, exp-001 recipe)

Hyperparameters inherited from exp-001 (smoothing ε=0.05, Adam
lr 3e-4, batch 4096, patience 3, seed 20260729); epoch cap raised to
400 so the patience rule genuinely terminated (exp-001's cap of 20
left v2 still climbing — more data, slower plateau).

- **Plateau at epoch 96, best epoch 93: masked val top-1 0.7980,
  val loss 0.789, entropy at convergence 0.783 > 0** (smoothed-target
  requirement holds).
- Per-group val accuracy:

| Group | n (val) | accuracy |
|---|---|---|
| move | 199,467 | 0.654 |
| rest/sleep/groom | 165,517 | 0.932 |
| eat/drink | 51,378 | 0.973 |
| **play/chase** (18–32) | 123,829 | **0.853** |
| meow (33–38) | 1,100 | 0.001 |
| idle | 30,745 | 0.528 |

- **Play/chase clones well** (0.853) — the class carrying the
  registered post-025 credit signal is faithfully represented in the
  scratch prior.
- **Meow does not clone**: dataset v2 carries 3,518 meow-labeled rows
  (0.18%; 774 from the s6 half, the rest scripted-expressible), and
  at that imbalance the clone essentially never predicts them (1
  correct of 1,100 val rows, 35 of them policy-sourced). §1 lever 4
  delivered meow *labels* into the scratch data, but C-scratch's
  *emission* prior is ≈0 — meow use in C-scratch must come from RL
  exploration (entropy > 0 keeps it reachable). Worth remembering
  when H3 screens C-scratch: warm-start arms inherit s6's channel
  use; the scratch control starts without it.

offset. Val includes the three held-out s6 rollouts, so EV is
measured out-of-sample on policy-like states too. 273,042 train /

## Reproduce

```
# from the repo root, on engine 0fd551d, dataset v2 in place (prereg §5)
V=experiments/exp-001-bc-mappo/trainer/.venv/bin/python
A=experiments/exp-002-mixed-population/artifacts/clone-v2
$V experiments/exp-002-mixed-population/trainer/clone_v2.py \
  --data-root experiments/exp-002-mixed-population/raw/bc-v2 \
  --out-dir $A --epochs 400
$V experiments/exp-002-mixed-population/trainer/critic_v2.py \
  --data-root experiments/exp-002-mixed-population/raw/bc-v2 \
  --out-dir $A --gammas 0.995,0.998 --epochs 200
$V experiments/exp-001-bc-mappo/trainer/export_artifact.py \
  --clone $A/clone.pt --out $A/clone.ckpolicy
$V experiments/exp-001-bc-mappo/trainer/parity.py --artifact $A/clone.ckpolicy \
  --clone $A/clone.pt --data-root experiments/exp-002-mixed-population/raw/bc-v2
./target/release/kitty-eval --artifact $A/clone.ckpolicy \
  --seeds 1,2,3 --ticks 20000 --roster both
```
