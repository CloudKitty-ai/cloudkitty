## Instrument finding: binding version skew (fixed before any comparison)

The shared harness venv (`exp-001-bc-mappo/trainer/.venv`) carries a
cloudkitty binding built 2026-08-09 — five days before spec 031 (shared
sunbeam warmth) merged. The Aug-15 bc-collect binary has 031. The
fingerprint probe's stitch check caught it: replaying bc-collect's seed
820001, the state traces split by exactly `sleep_relief_sunbeam −
sleep_relief` (3.0 points) on a pile-touching-a-beam sleep tick.

Consequences and fix:

- exp-005 now has its own venv (`.venv/`, gitignored) with the binding
  built from **pre-wall main 89b720a** — the frozen 197/34/9 surface the
  prereg pins, engine-consistent with the collection binary (031
  included, 033 not). Every live-env exp-005 instrument (fingerprint
  probe, PPO arms) uses it. A first clone probe run on the skewed
  binding was discarded before any comparison was read.
- Prior work is not retroactively broken: the certification battery's
  comparisons were seat-paired on one instrument, and D-001 already
  registers the python harness as an instrument distinct from the
  production engine. Noted for the cert record's forward notes.
- Standing lesson: instrument venvs should pin and print their engine
  commit.

## Fingerprint probe (`fingerprint_probe.py`)

Frozen metrics, demonstration composition (subject at Biscuit's seat,
three needs_driven), band 820001–820010 × 10,000 ticks, greedy.
Operationalization pin, set before any arm is measured: "within 2
tiles" = **Manhattan ≤ 2** (moves are axial, so Manhattan is the travel
metric).

Scripted mode stitches two instruments — decision metrics from a
bc-collect run at the probe band (`raw/fingerprint-scripted`, 399,171
decisions), trajectory metric + welfare from a python replay of the
same seeds — and proves the stitch by asserting state-trace equality
against `state.npy` at every 500th tick (excluding the last float, the
episode clock, whose normalization is horizon-dependent: bc-collect
chunks at 2000, the replay runs 10,000; the clock also *wraps* at the
horizon, so the clone trained on the full [0,1) clock range and the
probe stays in-distribution). Policy mode measures everything in one
live run.

## Results: the clone carries the fingerprint

| metric | scripted demonstrator | clone (greedy) |
|---|---|---|
| play_share | 0.6315 ± 0.0088 | 0.6739 ± 0.0064 |
| bug_over_meal | 0.2789 ± 0.0381 | 0.2873 ± 0.0410 |
| duet_initiation /1k | 153.64 ± 10.08 | 177.96 ± 15.08 |
| time_near_critters | 0.4492 ± 0.0264 | 0.4558 ± 0.0316 |
| subject happiness | 79.14 ± 0.13 | 78.94 ± 0.21 |
| team happiness | 87.48 ± 0.06 | 87.50 ± 0.15 |

(mean ± sd over 10 seeds; per-seed detail in
`artifacts/fingerprints/{scripted,clone}.json`, local)

The clone is slightly *more* playful than its teacher on every decision
metric — the exp-003 pattern (greedy argmax amplifies the modal
choice), not drift. Welfare is indistinguishable. The demonstrator's
happiness deficit vs the team (~8.3 points) is the personality itself:
playful runs itself ragged, and preserving that visible cost through
PPO is what the leash arms measure.
