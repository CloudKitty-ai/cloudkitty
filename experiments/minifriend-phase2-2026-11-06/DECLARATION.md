## 4. The graft and the training (recipe deltas only; everything else `train_ppo_g2.py` verbatim)

- **Graft** (ruling 3). Load trunk-s_k's `policy-final.pt`; widen the
  kitty embedding Linear(58 → 64) to Linear(58 + C → 64) with the new C
  columns ZERO; every other weight byte-equal. The arm's first forward on
  any observation therefore equals the trunk's (guard g1: logits equal to
  float precision on real recorded rows, before and after the graft,
  with the appended cells arbitrary). No other new parameter.
  **Instrument note 2026-11-06.** The widened map is held as two blocks
  — the trunk's Linear(58 → 64) untouched plus a bias-free Linear(C →
  64) on the cells, summed — the same linear map (Adam is elementwise,
  so the same training), because one wider matrix reproduced the
  trunk's logits only to 2e-5 (float accumulation order) while the
  two-block form is bit-equal; g1 asserts bit-equality. The grafted
  policy acts in eval mode wherever it acts (nn.TransformerEncoder's
  fused inference path differs from the training-mode path by ~1e-5;
  the trunk's own rollouts ran the training-mode path, as this arc's
  training does).
- **Head inference in the trainer** (ruling 7). One GRU state per
  (observer, friend) pair per world, reset at episode start, stepped
  every tick on the observer's own stream (self block + the friend's row,
  the act arc's forward); the head's outputs for friend j are appended to
  observer k's row j before the policy forward. Online inference must
  reproduce the offline readers (guard g2: on a recorded needy-set world,
  the online runner's per-tick outputs equal `read_act`'s / the Phase 1e
  loaders' to 1e-6 — the deployed condition is the read condition, gate
  DECLARATION §8 item 4).
- **Anchor and leash.** The anchor is the trunk seed itself, run on the
  un-widened rows (so it is exactly the trunk's distribution); β held at
  the frozen 0.04 from step 0 — no 0.5 → 0.04 anneal, because the arm
  starts AT the anchor (the anneal protected a BC clone's first steps;
  here it would only delay learning the new cells). Thread's reading of
  "recipe verbatim" for a warm start; reversible (§12 call 3).
- **Critic.** The pinned accepted critic-g2 over the ground-truth global
  state v2, continued as in the trunk run (the Adam state fresh, as any
  new run's). It never sees a head cell.
