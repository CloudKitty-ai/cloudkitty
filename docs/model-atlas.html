CloudKitty · policy architecture by generation

One mind, drawn five times

Every kitty policy is a per-tick, feedforward read of the world: a fixed-layout observation vector in, logits out. Two stories run through the five panels: the vector grows ears, and partway along the mind itself changes species, from a flat MLP that reads the vector as one long number to an entity-attention model that reads it as a scene. Each panel marks its deltas against the one before.

Why pointers matter: the MLP had to learn "play-with-slot-2" as its own unrelated output; the attention mind scores play-with-this-cat from that cat's representation, so what it learns about one friend transfers to every seat a friend can occupy. The activity head still reads out as the same 34-entry menu v2; the schema pin bumps to action v3 for the message-head widening alone, and the .ckpolicy v3 artifact format (spec 030) carries the new shape. The serving roster today: attn-a1-s1-o4, Biscuit 2.0 (e006a-L-04-s3), attn-a1-s3-o4 and e006-E1-s1 on this architecture; e004-a1-s2-o4, the exp-004 two-head MLP carried onto the schema-4 surface, still holds Clementine's seat.

  • Vision shrinks, hearing sharpens. Global → radius knowledge is the generation's point; the digest matrix is what keeps the world legible through it.
  • Scene-age everywhere. Partnered scenes show how long they've run: the input a play-proposal policy needs to judge "soon free."
  • Neighbour-in-water. The wet-fur price lands with the bit that lets a policy predict it.
  • Both heads frozen. The action and message layouts ride through untouched.

Reading the arc: two stories, out of phase. The vector's history is a history of hearing — 18 digest floats → 32 → 60 → a ~120-float per-speaker matrix, from "someone, somewhere, wants food" to "that cat, again, twice in ten ticks." The mind's history has one hinge, crossed seat by seat rather than at a stroke: flat 256×256 MLPs from the first generation, the entity-attention read (tokens, two encoder layers, pointer heads) arriving mid-v3 and holding four of five seats today, with one MLP incumbent still serving. Both minds answer to the same legality mask.
